# hxwl-04 逐牙根管治疗台账

按牙位组织根管治疗全过程：开髓 → 测长 → 预备 → 冲洗 → 封药 → 充填，逐步门控推进；根管工作长度逐根保存；复诊占用诊椅 60 分钟时段并当场检测同椅重叠。

## 功能

- **逐牙台账**：FDI 牙位图点选建账/打开，按牙位（36、11、46…）独立记录
- **步骤门控**：六步顺序推进，未完成上一步不能进入下一步；完成测长要求每根根管都已保存工作长度
- **根管长度**：MB/DB/P 等每根根管单独保存工作长度（mm，失焦即存），可改名、增删（充填前）
- **充填锁定与返修**：充填后全记录锁定，必须填写返修原因才能重新打开；前序步骤保留，返修原因留痕
- **复诊排班**：3 张诊椅、固定 60 分钟时段；同诊椅同日时段重叠时当场红色冲突说明，阻止提交；支持取消释放
- **分层持久化**：业务记录、排班状态、页面状态（当前视图/选中牙位）分别存入 localStorage 三个命名空间，关闭重开自动接着处理
- 操作历史时间线、病例步骤筛选、当日诊椅占用一览

## 技术栈

React 19 + Vite + TypeScript，纯前端、localStorage 持久化，无后端。

- `src/domain/`：纯领域规则（牙位模板、步骤门控、长度校验、时段冲突、种子数据），不依赖 React
- `src/state/`：Context store + 三个独立存储命名空间
- `src/components/`、`src/pages/`：展示与交互页面

## 本地运行

```bash
npm install
npm run dev          # http://localhost:5104
```

开发端口：5104

## 校验

```bash
npm run typecheck      # TypeScript 严格模式
npm run test:domain    # 41 项领域规则断言（门控/长度/返修/诊椅冲突）
npm run build          # 生产构建
```

首次打开自动写入 3 份示例台账（#36 预备中、#11 已充填锁定、#46 封药待复诊）与 2 条复诊；页面底部可恢复示例或清空全部数据。
