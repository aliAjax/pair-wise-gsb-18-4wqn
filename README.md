# hxwl-04 牙科根管治疗台账

按牙位组织根管步骤、工作长度与复诊计划。

## 功能

- **牙位图**：FDI 32 牙位点选建档，状态一眼可见（未建档 / 治疗中 / 已充填 / 返修标记）
- **治疗台账**：开髓 → 测长 → 预备 → 冲洗 → 封药 → 充填 固定顺序推进，未完成上一步不能进入下一步
- **根管长度**：每根根管单独保存工作长度，全部填齐才能完成测长，测长后长度锁定
- **复诊日程**：每次复诊占用诊椅 60 分钟，同一诊椅时段重叠当场提示冲突并阻止保存
- **返修**：充填后必须填写返修原因才能重新打开（回退封药与充填），返修原因留档
- **持久化**：台账与界面位置保存在 localStorage，关掉再打开接着处理

## 代码结构（记录 / 状态 / 页面分离）

- `src/lib/types.ts` — 数据模型
- `src/lib/records.ts` — 记录层：localStorage 读写、版本校验、示例台账
- `src/lib/treatment.ts` — 领域规则：步骤门禁、根管模板、时段冲突检测
- `src/state/useLedger.ts` — 状态层：台账状态与所有写操作
- `src/pages/` — 页面层：牙位图、治疗台账、复诊日程
- `src/App.tsx` — 组装与导航
